# homebrew-tap

Personal Homebrew tap.

| Formula | Project |
|---|---|
| `lukadispatch` | [LLawli/lukadispatch](https://github.com/LLawli/lukadispatch): keep driving your Claude Code sessions from your phone, over Telegram |
| `medx` | [LLawli/medx-sdk-oss](https://github.com/LLawli/medx-sdk-oss): CLI and MCP server for MedX, the medical clinic management system |
| `note` | [LLawli/note](https://github.com/LLawli/note) — take notes entirely from the terminal (CLI + TUI) |
| `sora` | [LLawli/sora](https://github.com/LLawli/sora) — distrobox commands as if they were native host commands |
| `xclaude` | [LLawli/XClaudeDashboard](https://github.com/LLawli/XClaudeDashboard) — real-time TUI dashboard for [XClaudeUsage](https://github.com/SrDarf/XClaudeUsage) |

## Usage

```sh
brew install LLawli/tap/lukadispatch
brew install LLawli/tap/medx
brew install LLawli/tap/note
brew install LLawli/tap/sora
brew install LLawli/tap/xclaude
```
